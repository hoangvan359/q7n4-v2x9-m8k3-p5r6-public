# Ad Template Research Presentation

Standalone HTML presentation and its runtime assets.

## View locally

Open `present-scroll__2026-Q3.html` directly in a browser, or run a local static server from the repository root:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000/present-scroll__2026-Q3.html`

## Structure

- `present-scroll__2026-Q3.html` — presentation source.
- `present-site-assets/` — images and videos referenced by the HTML.
- `runtime-assets.txt` — generated list of runtime asset paths.

All runtime paths are relative to the repository root. Keep the HTML and `present-site-assets/` directory together.
